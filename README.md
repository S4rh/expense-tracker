# Expense Tracker

A small Python command-line expense tracker built while learning programming.

## Features

- Add expenses
- View expenses
- Calculate total expenses
- Calculate totals by category
- Edit expenses
- Delete expenses
- Validate user input
- Save expenses to a JSON file
- Load saved expenses when the program starts

## How to run

Make sure Python is installed, then run:

python expense_tracker.py

## Tests

Run:

python test_expense_tracker.py
